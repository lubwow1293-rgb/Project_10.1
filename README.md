# Data Processing Toolkit

Легковесный модуль для обработки и фильтрации коллекций данных (списков словарей). 

Проект предоставляет готовые утилиты для типовых задач: фильтрации записей по статусу и сортировки по дате. Инструментарий спроектирован так, чтобы не изменять исходные данные, а всегда возвращать новые списки, что гарантирует отсутствие побочных эффектов в вашем коде.

## Цель проекта

Предоставить простые и надежные функции для предварительной обработки данных перед их дальнейшей передачей в API, сохранением в базу данных или отображением в пользовательском интерфейсе. Модуль избавляет от необходимости писать повторяющийся код для фильтрации и сортировки словарей вручную.

## Установка

1. Убедитесь, что у вас установлен Python версии 3.8 или выше.
2. Проект не требует сторонних зависимостей и использует только стандартную библиотеку Python. Для работы достаточно стандартной среды выполнения.
3. Склонируйте репозиторий или скопируйте папку `src` в корень вашего проекта.
